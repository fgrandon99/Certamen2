# Sitio Web Café Universitario:
Sitio web estático desarrollado para la empresa Café Universitario, un emprendimiento local 
dedicado a la venta de café, pastelería y productos artesanales.

## Desarrollado con:
- HTML
- CSS
- JavaScript

## Secciones:
- **Header**: menú fijo con enlaces a cada sección
- **Banner**: imagen background con texto de bienvenida
- **Seccion Nosotros**: información de la empresa
- **Seccion Productos**: catálogo con 3 productos disponibles
- **Seccion Contacto**: formulario de solicitud de información
- **Formulario y Solicitudes**: tabla con los registros ingresados
- **Pie de Pagina**: información de contacto y redes sociales

## Funcionalidades
- Navegación suave entre secciones
- Formulario de solicitud de información
- Visualización dinámica
